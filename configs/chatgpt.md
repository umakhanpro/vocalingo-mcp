# ChatGPT

1. Open [chatgpt.com/plugins](https://chatgpt.com/plugins) → **+** → **Add custom MCP server**. Availability depends on your plan and workspace policy; on some accounts you first need to enable Developer mode in settings.
2. Name `VocaLingo`, MCP server URL `https://nodejs.vocalingo.app/mcp`, authentication **OAuth** → **I understand and want to continue** → **Create**.
3. Sign in to VocaLingo (email code, Google, or a one-time code from the app: **Settings → AI agents (MCP)**) and allow access.

**Files:** attach a voice message, video or photo to your message — ChatGPT passes it to the tool directly. A link (YouTube, TikTok…) can simply be pasted. If an attachment doesn't come through, ask ChatGPT for the upload page link from `get_upload_url`.
